環境

環境欄位詳細說明
名稱同一 Repo內的環境識別名稱，例如 local、sit、uat；請避免重複。
Base URL真正接收測試 Request 的服務位址，例如 http://localhost:8080 或 https://api-uat.company.local。請先確認目標不是正式環境。
OpenAPI Path附加在 Base URL 後取得規格的路徑；Springdoc 預設常見為 /v3/api-docs。
Timeout 秒單一 Request 最長等待時間。內網服務可先用 30 秒；太短會把慢速 Response 判定為連線失敗。
SSL預設應啟用憑證驗證。只有受信任的內部測試環境使用自簽憑證、且確認風險後才停用。
環境共用 Header只套用目前環境，例如不同環境的 X-Tenant-ID。同名 Header 會覆蓋 Repo 共用設定。

Header 套用順序：全域 → Repo → 環境 → 本次執行 → 單一案例；後面的同名設定會覆蓋前面。

完整 Config JSON

進階功能：一般設定請優先使用「資料庫」與「Repo 與環境」表單。只有需要一次調整巢狀設定、複製設定或排查問題時，才直接編輯 JSON。
完整設定編輯規則
  • 內容對應 EXE 旁的 config.yaml，按「儲存設定」後才會寫入。
  • 必須是合法 JSON：屬性名稱與文字需使用雙引號，最後一項不可多逗號；格式錯誤時不會儲存。
  • 密碼顯示為 ******** 時，直接儲存會保留原密碼，不會把星號當成新密碼。
  • 修改 Repo ID 可能讓既有案例無法在原 Repo下顯示；建立案例後應保持 ID 不變。
  • 不熟悉欄位結構時，請回到一般表單修改，避免刪除 projects、environments、database 等必要區段。

建議大量修改前先複製一份 config.yaml 作為備份。

使用說明

從建立 Repo到產生測試報告的完整操作流程
快速上手

第一次使用

1到「系統設定」建立 Repo 與環境
2設定 Base URL 與共用 Header
3匯入 API 或新增手動 API
4編輯案例後勾選執行
建議先使用 Local／測試環境。命中 prod 或 production 的 Domain 會被工具阻擋。

1. Repo 與環境設定

開啟「系統設定 → Repo 與環境」，依序填寫：

  • Repo ID／名稱：用來識別不同 Spring Boot 系統。
  • Repo 路徑：需要直接掃描 Spring Boot 原始碼時設定。
  • Base URL：實際執行測試的目標，例如 http://localhost:8080。
  • OpenAPI Path：Springdoc 通常是 /v3/api-docs。
  • Token Header：例如 Authorization 與 Bearer Prefix。

修改完成後請按右上角「儲存設定」。

2. 載入 API 清單

來源適用情境操作
已保存案例使用先前匯入並調整過的資料選擇後按「載入／匯入 API」
OpenAPI URLSpring Boot 已啟動且可讀取 /v3/api-docs確認環境後匯入
Spring Boot Repo從 OpenAPI 文件或 Controller Annotation 掃描先在 Repo設定 Repo 路徑
新增手動 API目前沒有 Repo 或 OpenAPI直接填 Method、Path 與 Request

3. 編輯測試 Request

在 API 清單按「編輯」，可以設定 Path Parameter、Query Parameter、案例 Header、Content-Type、Request Body 與預期結果。

Header 套用順序如下，後面的設定會覆蓋前面：

全域 Header → Repo Header → 環境 Header → 本次執行 Header → 單一案例 Header

Token 僅供本次執行使用，不會保存；Authorization、Cookie、API Key 會在報告遮罩。

4. 從 DB2／Oracle 產生 Request（選用）

  1. 到「系統設定 → 資料庫」選擇 DB2 或 Oracle。
  2. 填寫連線資料、Schema、Table 及欄位對應。
  3. 確認 api_name 對應實際的 API_NAME 欄位。
  4. 先使用「測試資料庫連線」。
  5. 回到案例編輯畫面，按「從 DB 歷史紀錄產生」。
  6. 系統會保存查到的 Request，之後仍可手動調整。

預設 Table 範例為 ADM_API_ACCESS_LOGS；請依實際系統修改。

5. 執行測試

  • 單筆：在 API 右側按「執行」。
  • 多筆：勾選需要的案例，再按「執行勾選項目」。
  • 全部：按「執行全部啟用案例」。

工具會驗證預期 HTTP Status、Return Code JSON Path、成功業務碼及最大回應時間。未勾選任何案例時不會誤執行全部。

6. 報告與資料位置

每次執行會同時產生 HTML 與 JSON。可在「報告歷史」搜尋、查看 Request／Response 與錯誤訊息。

config.yamlRepo、環境、資料庫及全域設定
test-data.dbAPI 清單、測試案例與報告索引
reports/HTML 與 JSON 報告

7. 正確關閉工具

可以直接關閉操作頁面，瀏覽器會先詢問是否離開；確認後約 3 秒會停止本機服務並釋放 Port 8765。也可以使用左側「關閉工具」按鈕。

重新整理頁面會自動重新連線，不會誤關服務。
